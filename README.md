# Student Performance Prediction 🎓

A Machine Learning web application that predicts a student's final grade using Multiple Linear Regression.

## 🚀 Live Demo

[Click here to use the application](https://student-performance-prediction-nhscnxk38p2qykrsbsa7uu.streamlit.app/)

## 🛠️ Technologies Used

- Python
- Pandas
- Scikit-learn
- Multiple Linear Regression
- Joblib
- Streamlit

## 🎯 Project Objective

The goal of this project is to apply Machine Learning concepts by training a regression model and deploying it as an interactive web application.
